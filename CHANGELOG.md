# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
(sort of).

## [0.2.0] — 2026-10-18

### Added
- `emily_fortune.py` — snake fortune teller with fifteen fortunes and batch mode.
- Four arcade mini-games in `emily_surprise.py`: Guess the Number,
  Rock-Paper-Scissors, Snake Math Quiz, and a Reaction Test — scored on a
  persistent per-user leaderboard.
- Poetry system (hex-color rhymes, indentation verse, free verse) in
  `emily_surprise.py`.
- Quote generator with curated snake wisdom.
- `snake-ci.yml` — CI workflow running smoke tests on all three scripts.
- Governance suite: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, .gitignore,
  .gitattributes.

### Changed
- README rewritten with full feature table, architecture tree, and updated
  badge URLs.
- Repository migrated from `hiss-terical-python` to `hissterical-python`
  (no hyphen, fewer headaches).

### Silliness
- The snake is still happy. The CI is still passing. The governance is still
  taken completely seriously. This contrast remains the architecture.
