# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x: (the snake was not yet born) |

## Reporting a Vulnerability

If you discover a vulnerability in hiss-terical-python, please do NOT open a
public issue. Instead, email the maintainer directly.

Please include:
- A description of the vulnerability.
- Steps to reproduce.
- Whether the snake is okay.

You will receive a response within 48 hours. If the vulnerability involves the
slither dance, response time may vary depending on the snake's mood.

## Known Security Considerations

- The snake has no authentication. This is by design. The snake trusts everyone.
- Compliments are generated from a fixed list. There is no risk of
  compliment injection.
- The ASCII snake is not cryptographically signed. We accept this risk.
- Running `emily_surprise.py` with elevated privileges is unnecessary and
  frankly weird. Don't do that.

## Scope

This policy covers the scripts in this repository. It does not cover your
feelings after receiving a compliment from a snake. Those are your own.
